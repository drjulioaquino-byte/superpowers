# Origem e adaptações

As quatro skills de apoio foram adaptadas por Codex, por solicitação de Júlio,
das técnicas do Superpowers no commit
`22f0b463e7a5e579904dd6211a520321035526f7`.

| Skill deste pacote | Fontes no Superpowers |
| --- | --- |
| diagnostico-com-evidencia | systematic-debugging e condition-based-waiting |
| testes-com-contraprova | test-driven-development e writing-good-tests |
| planejamento-por-contratos | writing-plans |
| verificacao-de-entrega | verification-before-completion |

As adaptações mantêm a revisão Claude e as decisões do Human, aplicam as técnicas
conforme a tarefa e priorizam evidência válida, preservação de dados e contratos
existentes. O fluxo principal foi fornecido por Júlio e recebeu vínculos para
essas quatro skills de apoio.

O aviso de copyright e os termos MIT da origem estão em [LICENSE](LICENSE) e nas
pastas das skills derivadas. As referências de origem em cada skill apontam para
a revisão examinada.
